# BudgetWise — Contexte complémentaire pour le futur prompt maître VS Code

Le futur assistant de développement doit lire l'ensemble des documents 01 à 05 ainsi que ce complément. Le projet suit 75 décisions de conception, complétées par une fonctionnalité validée après clôture.

## Fonctionnalité complémentaire approuvée
**Assistant intelligent Aurora Premium de répartition du budget selon les revenus (option C).** Il doit pouvoir proposer plusieurs répartitions (dont 50/30/20), intégrer revenus estimés/variables et charges fixes, montrer le montant restant, simuler des modifications, laisser ajuster les propositions et demander une confirmation explicite avant de créer ou modifier des budgets. Aucune opération bancaire ni transaction n'est effectuée par l'assistant. Prévenir les doubles comptes et les dépassements. Priorité MVP ou 1.x non encore décidée.

## Méthode de collaboration souhaitée
Guider l'utilisateur pas à pas, expliquer les choix et lui laisser écrire le code ; ne pas construire l'application entière d'un coup. Lire les fichiers réellement présents dans le dépôt, vérifier les acquis à chaque étape, ne pas supposer que les fonctionnalités décrites sont déjà implémentées, distinguer décisions validées et détails encore ouverts.

Ce fichier est un complément de contexte, pas encore le prompt maître définitif.
